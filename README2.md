# Rock, Paper, Scissors Game

A simple command-line game built with Python.

## How to Play
1. Run the script.
2. Type `0` for Rock, `1` for Paper, or `2` for Scissors.
3. The computer randomly picks its move, and the winner is announced!

## Concepts Used
* `random.choice()` for selection
* Conditional logic (`if`, `elif`, `else`)
* Lists and indexing
